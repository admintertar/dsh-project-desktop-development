# 隐藏聊天页重复的工作区入口

## 需求与实现

项目已由 Shell 窗口确定，聊天输入框上方无需再次选择工作区。Project 插件在成功识别当前项目后替换官方 `conversation.hero.workspace` 插槽，并通过其公开的 `anchorRef` 隐藏插槽外的工作区按钮。项目加载失败或插件退出时恢复官方入口及原有内联样式。

标准模式、模型、权限和输入框继续使用官方实现。原有项目根工作区创建、打开及新会话绑定逻辑不变。官方 0.2.0-rc.2 暂无按钮可见性选项，最小适配已登记于 `THIRD_PARTY_NOTICES.md`，未修改官方源码或构建产物。

插件本地提交：`90ea335`（隐藏项目聊天页重复的工作区入口）。开发壳使用本地插件构建；未推送、未变更发行 pin。

## 验证

- 插件 `yarn run check` 通过：类型检查、308/308 项测试、构建。
- macOS arm64 真实 Shell 临时项目窗口：中文/深色 1280×820、英文/浅色 852×672 均确认工作区按钮不显示且无布局占位；标准模式可见、输入框可编辑、无横向溢出。
- 原生 Tab 遍历不会聚焦隐藏的入口；官方工作区存储仍指向测试项目根目录。
- 用户现有 `dsh-project-desktop-development` 窗口刷新后，从概览打开新项目会话，工作区按钮隐藏、标准模式可见、输入框为空且可编辑；已确认隐藏按钮仍关联当前项目。
- 临时验证实例已正常退出。截图与 JSON 来自独立临时项目，不包含用户账号、认证或运行 Profile；运行数据未放入任务目录。
